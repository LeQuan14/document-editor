# Document Editor

A local first (hopefully) collaborative text editor.

### Tech Stack
- Frontend:
    - React
- Editor-Core:
    - Tiptap
- CRDT-Engine:
    - Yjs
- Local storage:
    - y-indexeddb
- Sync-Server:
    - y-websocket (Jode.js)
- Persistence:
    - SQLite

----

CRDT = Conflict-free Replicated Data Types
